Lembre

Cada 0 ou 1 é um bit. Oito bits formam um byte, que guarda um número de 0 a 255 (são 28 = 256 possibilidades). As casas valem 128, 64, 32, 16, 8, 4, 2 e 1. No código ASCII, criado em 1963, cada letra tem um número: A = 65, B = 66, …, Z = 90; as minúsculas começam em a = 97.
